Powerful & Safe

Designed for Complete Desktop Freedom

Personalize your app launchers and icons cleanly without root permissions or modifying package-managed files.

Safe User-Level Overrides

Never modifies system files in /usr/share/applications. Creates compliant FreeDesktop XDG overrides in ~/.local/share/applications that preserve original packages.

Drag & Drop Icon Replacement

Simply drag and drop any image (SVG, PNG, WebP, JPG) directly onto the 96px icon preview, or browse your files to set your favorite custom artwork.

Custom Display Names

Rename any application launcher right from the app page with automatic locale stripping and an instant one-click undo (↺) button.

Instant One-Click Restore

Easily revert individual icons and names, or click "Restore All to System Default" to safely wipe overrides and restore upstream package defaults.

Inspect & Test Launch

Inspect the resolved Desktop file, App folder, and start Command with direct links to open locations in Files, plus a header Launch button to test immediately.

Universal Compatibility

Works seamlessly across GNOME, KDE Plasma, COSMIC, Cinnamon, XFCE, and handles System packages, Flatpaks, Snaps, and local AppImages.

How It Works

Clean Customization in Three Steps

No command line editing of .desktop files required.

1

Select an Application

Open Glyph and search through all installed desktop applications, or filter to see only apps you have customized.

2

Customize Icon & Name

Drop your favorite SVG or PNG icon onto the preview and adjust the display name to match your personal setup.

3

Enjoy & Restore Anytime

Your desktop menu and dash update automatically. If you ever change your mind, restore stock defaults with a single click.

Privacy & Security

Engineered for Peace of Mind

Full desktop freedom with zero compromises to your system integrity or personal privacy.

100% Offline & Private

Zero internet permissions, zero telemetry, and zero analytics. No background network requests ever leave your machine. Your application habits stay completely private.

Non-Destructive User Space

Never touches or modifies root files in /usr or /var. Overrides live strictly in standard ~/.local/share/applications and can be cleanly reverted at any time.

Read-Only Discovery

Filesystem access to system and Flatpak folders is strictly read-only. It is used exclusively to discover installed .desktop launchers and display application icons across RPM, DEB, AUR, and Flatpak.

Desktop Portal Isolation

File chooser dialogs execute through native FreeDesktop portals. Glyph only receives temporary access to the specific image files you manually choose in the system picker.

Terminal & Developers

Source & Arch Installation

Prefer using the command line or building locally? Run directly in user space without root.

⚡

Run Instantly from Source

Zero compilation required. Clone and launch directly with Python 3, GTK4, and Libadwaita:

git clone https://github.com/the0megastar/Glyph.git && cd Glyph && ./run.sh
🏔️

Arch Linux (Pacman & AUR)

Install the pre-built package directly with pacman, or build with makepkg:

sudo pacman -U glyph-*-any.pkg.tar.zst

Release Notes

Glyph v0.1.2

Latest Release • September 5, 2026
Latest GitHub
  • Strict Flatpak Scoping - Replaced broad filesystem permissions with strictly scoped access to /var/lib/flatpak/exports/share:ro and /var/lib/flatpak/app:ro (and user equivalents). Completely locks out system runtimes, ostree objects, and repo metadata.
  • Default Sandbox Isolation - Removed explicit host permissions for app state, relying exclusively on private sandboxed storage (XDG_DATA_HOME) for custom icons and backups.
  • Full Host Boundary Protection - Completely eliminated host:ro and host-os:ro to satisfy Flathub security guidelines and isolate user personal files, documents, and credentials.
  • Granular Launcher Overrides - Maintained scoped write access solely for user desktop overrides (~/.local/share/applications) and read-only user icon themes (~/.local/share/icons).
  • Multi-Architecture Release Pipeline - Verified builds across 64-bit PC (x86_64) and ARM64 (aarch64) across Flatpak, AppImage, deb, rpm, and Arch Linux packages.
