Privacy & Security

Personalize with peace of mind.

Your customizations stay in your user account. Original package files stay intact.

100% Offline & Private

Zero internet permissions, zero telemetry, and zero analytics. No background network requests ever leave your machine. Your application habits stay completely private.

Non-Destructive User Space

Never touches or modifies root files in /usr or /var. Overrides live strictly in standard ~/.local/share/applications and can be cleanly reverted at any time.

Read-Only Discovery

Filesystem access to system and Flatpak folders is strictly read-only. It is used exclusively to discover installed .desktop launchers and display application icons across RPM, DEB, AUR, and Flatpak.

Desktop Portal Isolation

File chooser dialogs execute through native FreeDesktop portals. Glyph only receives temporary access to the specific image files you manually choose in the system picker.

Download a Linux package ↗

Flatpak, AppImage, and native packages. Availability varies by release.

Install a downloaded package

Open a terminal in the folder containing your download. Examples use v0.1.3; use the filename you downloaded.

Fedora

Install the downloaded RPM with DNF. It also installs required dependencies.

sudo dnf install ./glyph-0.1.3.rpm

Debian / Ubuntu

Install the downloaded DEB with APT. Your distribution must provide compatible dependencies.

sudo apt install ./glyph-0.1.3.deb

Arch Linux

Install the downloaded Arch package with pacman. No build step is needed.

sudo pacman -U ./glyph-0.1.3-1-any.pkg.tar.zst

Flatpak

With Flatpak installed, install the bundle for your user account. A runtime download may also be needed.

flatpak install --user ./Glyph-0.1.3-x86_64.flatpak

The example is for x86_64. For ARM64, download the aarch64 file and use that filename instead.

AppImage

Make the downloaded file executable, then run it.

chmod +x ./Glyph-0.1.3-x86_64.AppImage ./Glyph-0.1.3-x86_64.AppImage

The example is for x86_64. For ARM64, download the aarch64 file and use that filename instead.

Run from source

Zero compilation required. Clone and launch directly with Python 3, GTK4, and Libadwaita:

git clone https://github.com/the0megastar/Glyph.git && cd Glyph && ./run.sh
